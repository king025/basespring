## Introduction
This is a simple program designed to help onboard developers with JWT tokens and encryption.

## How to use
All endpoints can be seen in GreetingController.java. 

Deploy the application by running the command below  
```bash
mvn spring-boot:run
```
This would run the spring-boot project locally and will listen to the default port 8080

Once the server is up, you can use the following link to test your connection [Hello World](http://localhost:8080/greeting)
