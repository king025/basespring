# Spring Boot 3 - Junit Mockito

Sample JUnit test classes with Mockito in Spring Boot 3 application.

--------------------

PREREQUISITE


- IDE (Java 17, Spring Boot 3.0.x, Maven, SonarLint)
- Docker (MongoDb image)
- Postman

--------------------

MAVEN DEPENDENCIES

		<dependency>
			<groupId>org.springframework.boot</groupId>
			<artifactId>spring-boot-starter-test</artifactId>
			<scope>test</scope>
		</dependency>

		<dependency>
			<groupId>junit</groupId>
			<artifactId>junit</artifactId>
			<scope>test</scope>
		</dependency>

--------------------

POSTMAN

Available in the postman collection folder.
- SpringBoot3JunitMockito.postman_collection.json
