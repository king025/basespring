# Legstar

### What is Legstar?
LegStar is a set of development tools and execution runtimes aimed at integrating legacy COBOL applications with Java and SOA technologies.
### Reference Documentation & Video
* [Legstar Website](https://www.legsem.com/legstar/)
* [COBOL in 100 seconds](https://www.youtube.com/watch?v=7d7-etf-wNI)

### TechStack
* [Spring boot 2.7](https://spring.io/)
* [Java 11](https://www.java.com/en/)
* [Legstar](https://www.legsem.com/legstar/)
* [Ant](https://ant.apache.org/)

### Setup Guide:
- Download and install
    - [Postman](https://www.postman.com/)
    - [JDK 11](https://java.com)
    - [Intellij](https://www.jetbrains.com/idea/)
    - [How to use Legstar Guide](https://confluence.nttltd.global.ntt/pages/viewpage.action?spaceKey=BU&title=Legstar+Documentation)


- Import [Legstar.postman_collection.json](src%2Fmain%2Fresources%2Fpostman%2FLegstar.postman_collection.json) to Postman
- Open source code in intellij
- Build Gradle and Run Springboot
- Execute API Requests in Postman
