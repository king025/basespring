# Building Docker Images using Maven Springboot 

To Build the docker images we used plugins in our POM.xml namely
- io.fabric8 -> docker-maven-plugin
- google cloud tool -> jib-maven-plugin


## Pre-requisite
docker desktop must be installed in your device.
