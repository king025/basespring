# Spring Boot - Exception Handling

Sample springboot project to demonstrate exception handling
--------------------
## Pre-requisites

- IDE (Java 17, Spring Boot 2.7.x, Maven)
- Docker (MongoDb image)
- Postman

--------------------

POSTMAN
Available in the postman collection folder. 

-Employee Springboot2.postman_collection.json

--------------------
#### MongoDB in Docker
Run a MongoDB docker image  before running the app in IDE. Run the following commands by order.

sample - docker compose -f .\IdeaProjects\employee-springboot2\docker-compose.yaml up
```bash
docker compose -f <path>\docker-compose.yaml up
```
