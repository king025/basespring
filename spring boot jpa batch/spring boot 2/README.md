# Versions
  Java 17
  
  Spring Boot 2
  
  Spring Batch 3.4.7
  
# CSV file location

  root folder
  
# Flow

  The App will automatically read the CSV and save the details to the PostgreSQL by passing the parameter enable in BatchController(http://localhost:8080/batch/)
